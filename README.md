# Valentine's Special

A handcrafted, interactive Valentine's Day experience — because some questions deserve more than a text message.

## What Is This

An animated web app that asks that one special person to be your valentine. It doesn't take "no" for an answer (gracefully), and rewards a "yes" with a scrollable photo gallery, parallax animations, and a love letter that unfolds from an envelope.

## The Experience

1. **The Question** — A playful prompt with puppy GIFs and growing buttons
2. **The Gallery** — 13 photos layered in a 3D parallax scroll
3. **The Letter** — An animated envelope that opens to reveal a handwritten-style love note

## Tech Stack

- **React** + **TypeScript** + **Vite**
- **Tailwind CSS** for styling
- **Framer Motion** for scroll-driven animations and transitions
- **Express** backend serving the static build

## Getting Started

```bash
npm install
npm run dev
```

The app runs at `http://localhost:5000`.

## Build

```bash
npm run build
npm start
```
